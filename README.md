### What I Believe

An ideal program is not the one that is perfect on paper. It is the one that is modular, maintainable, functional, and works.

**Pragmatic Engineering** — the wisdom to know the right tool for the right job, free from language bias. You may write a Rust todo app as a learning exercise, but for industry use, it might be overkill. As engineers, we must think about the problem first, not the language. Complexity accepted in development should justify the lack of complexity in future maintenance time.

Temporary bad engineering choices equal long-term bad products.
